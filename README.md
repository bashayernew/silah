# SILAH (صلة) – Smart Family Care & Medication Reminder

A family-care web application that helps elderly users manage medication, appointment and daily-task reminders.

**Group 208 · Kuwait Technical College · Supervisor: Ms. Annet Noel**

## Progress

| Week | Status | Work |
|---|---|---|
| 1 | ✅ Complete | Planning & design: project idea, main features, user workflow, security requirements, technology stack |

## Week 1 – Completed deliverables

1. Finalized the SILAH project idea: a family-care application that helps elderly users manage medication, appointment, and daily-task reminders.
2. Identified the main features, including personalized voice reminders, Arabic and English support, reminder responses, missed-reminder follow-up, and secure family linking.
3. Documented the user workflow, family dashboard, reminder-response process, and key security requirements.
4. Proposed the prototype technology stack: HTML, CSS, JavaScript, Python Flask, and SQLite.
